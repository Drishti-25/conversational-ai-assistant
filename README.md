# 🤖 Conversational AI Assistant

A lightweight **LLM-powered conversational application** built with Python and Streamlit, focused on **prompt engineering and controllable AI behavior**.

## ✨ What it Demonstrates

* **Prompt Engineering** — Custom system prompts to control the assistant's role, tone, and response style.
* **Conversational AI** — Maintains context across multi-turn conversations using the Gemini Interactions API.
* **Python Web Development** — Interactive web interface built with Streamlit.
* **LLM Integration** — Gemini API integration with secure API-key management.
* **Deployment** — Hosted using Streamlit Community Cloud.

## 💡 Why I Built It

Many organisations are building LLM-powered agents and designing prompts for real-world workflow automation. I built this project to explore the **conversational intelligence and prompt-engineering side** of LLM applications in a simpler, user-facing setting.
